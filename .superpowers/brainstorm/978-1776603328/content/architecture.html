AI Provider Logic

Server checks per request:
1. Does this user have a stored Anthropic API key? → use Claude API (their cost)
2. No key? → use Gemini Flash free tier (your cost: £0)
3. Gemini free quota exceeded? → graceful fallback message to user

Key stored: Encrypted in PostgreSQL, never exposed to client. User can add/remove in Settings.
